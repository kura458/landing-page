# Landing Page

A responsive landing-page practice project built with **HTML5** and **CSS3** as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

<text></text>

## Live preview

[Open the deployed page](https://kura458.github.io/landing-page/)

## Page sections and layout

- Hero section with a call-to-action
- Information cards with images
- Testimonial or quote section
- Closing call-to-action banner

## Built with

- HTML5
- CSS3
- Flexbox for page layout
- Google Fonts (Roboto)

## Run locally

Clone the repository:

```bash
git clone https://github.com/kura458/landing-page.git
cd landing-page
```

Open `index.html` in a browser. No package installation or build process is required for this static HTML/CSS project.

## Learning goals

This project provides practice with:

- Structuring a multi-section webpage
- Building layouts with CSS Flexbox
- Styling reusable content sections
- Organizing images and static assets
- Creating a clear visual hierarchy and calls to action

## Project status

This is a front-end practice project. The page is a static landing page; the call-to-action elements should not be assumed to connect to a backend or perform application workflows.
