# Landing Page

A clean and modern landing page built as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

## Live Demo

[View Live Site](https://kura458.github.io/landing-page/)

## Features

- Clean and modern design
- Flexbox layout
- Hero section with call-to-action
- Information cards with images
- Testimonial / quote section
- Call-to-action banner
- Fully styled with custom CSS

## Technologies Used

- HTML5
- CSS3 (Flexbox)
- Google Fonts (Roboto)
